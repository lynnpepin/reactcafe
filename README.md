
I've been programming in one form or another since I was seven or eight. I am comfortable with HTML, and I'm experienced in fullstack web dev. Despite decades of experience, I've barely ever touched React or Next.js. These are very in-demand tools, and I want to see if the grass is really greener. Much as Svelte and SvelteKit beckon, I want to be where the party is, and that's in Reactland.

Most recently, I come from C#/.NET + Angular land. I liked C# a lot more than I expected to (despite some qualms with its tooling and Microsoft), but I really did not like the indirection and (often fruitless) repetition of MVC. I had similar woes with the indirection and repetition of Angular. In many cases, one is repeating themself in a way that feels like a flaw of the framework design. I write this paragraph knowing little of React, hoping it fixes this.

I know frameworks are unfairly maligned for slowness and I get the sense that React is maligned just for being the posterchild of frameworks. I suspect even React Native might have a place. (I created KDE desktop apps using Qt before, which was a remarkably-web-like experience, after all.)
